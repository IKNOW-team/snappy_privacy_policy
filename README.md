# プライバシーポリシー

本プライバシーポリシーは、モバイルアプリケーション **「SNAPPY」**（以下「本アプリ」）における、ユーザーの個人情報およびデータの取扱いについて定めるものです。  
本アプリをご利用いただく前に、本ポリシーをよくお読みください。  


## 1. 収集する情報
本アプリは、以下の情報にアクセス・利用する場合があります。  

- 端末内のスクリーンショットや画像（OCR処理・タグ付けのため一時的に利用）  
- アプリの利用状況やクラッシュ情報（品質改善のため）  

なお、端末内のスクリーンショットや画像の取得は、お客様の同意を得た場合のみ行われます。  

## 2. 利用目的
収集した情報は、以下の目的で使用されます。  

- 端末内のスクリーンショットや画像の表示・管理  
- Google の外部AIサービスを利用した文字認識（OCR）および自動タグ付け機能の提供  
- アプリの利便性向上・品質改善  

## 3. 外部サービスの利用
本アプリは、以下の外部サービスを利用してデータ処理を行う場合があります。  

- **Google Cloud Vision API**  
  端末内のスクリーンショットや画像を送信し、文字認識（OCR）を行います。  

- **Google Generative AI（generative-ai API）**  
  OCR結果や画像の内容をもとにタグ付けを行うため、画像またはテキストデータを送信する場合があります。  

これらのサービスは Google LLC により提供されており、Google のプライバシーポリシー（https://policies.google.com/privacy） に基づいて処理されます。  

なお、本アプリは送信した画像データや認識結果を自社サーバーに保存することはなく、処理結果はユーザー端末にのみ返却されます。  


## 4. 情報の第三者提供
本アプリは、以下の場合を除き、ユーザーの個人情報を第三者に提供することはありません。  

- ユーザーの同意がある場合  
- 法令に基づく場合  
- 人の生命、身体または財産の保護のために必要がある場合  


## 5. セキュリティ
送信されるデータは、通信の際に暗号化され、適切に保護されます。  


## 6. プライバシーポリシーの変更
本プライバシーポリシーの内容は、必要に応じて改定される場合があります。変更後のプライバシーポリシーは、本アプリまたは配布ページ上に公開された時点から効力を生じます。
